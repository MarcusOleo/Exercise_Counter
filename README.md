# Exercise_Counter

This is a python based program used to count the reps for specific exercises - Bicep Curls, Squats, Push Up's, Jumping Jacks.

# Features
- Live video feed : shows a live video of your body movements with landmarks and wireframes attached.
- Live State feed : shows you current position of the body relative to the exercise. You can either be up or down.
- Rep Counter : this basically counts the number of reps for each exercise.
- Exercise Options : Allows you to select the exercise you want to track amongst the available options.
- Timer : keeps track of the time from start time to pause time.
- Reset Button : allows you to reset all parameters and take the system back to default mode.
